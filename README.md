# IT Piazza static website — first migrated page

This package is ready to upload to the root of the GitHub repository `anauz/itpiazza`.

Included:
- `/index.html` — temporary home page during phased migration
- `/publications/index.html` — migrated Publications page
- `/publications/assets/` — local images used by the page

GitHub upload:
1. Extract the ZIP.
2. Open the `itpiazza` repository.
3. Choose Add file → Upload files.
4. Upload `index.html` and the `publications` folder into the repository root.
5. Commit to the `main` branch.

Cloudflare Pages will deploy automatically.
The migrated page will be available at:
https://itpiazza.net/publications/
